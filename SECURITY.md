# Security Policy

If you find a bypass, major false negative, or a security-sensitive issue in ClickArmor:

- please avoid posting full bypass details publicly right away
- open a private security advisory on GitHub if that feature is enabled for the repository
- if private reporting is not available yet, use a direct contact path you already have for the maintainer

## Please include

- the affected page or workflow
- whether the issue is ClickFix, credential phishing, brand impersonation, clipboard abuse, or AiTM-related
- reproduction steps
- screenshots or sanitized samples if available
- the expected detection behavior versus what actually happened

## Disclosure preference

Responsible disclosure is appreciated. The goal is to fix issues quickly without handing working bypasses to attackers before defenders can react.
